rclone backup

A private, single-user Google OAuth client. It lets the open-source tool rclone, running on the owner's own computer, copy the owner's files into the owner's own Google Drive as a backup. It is not offered to anyone else.

Privacy policy

  • The app asks only for the drive.file permission: it can see and change only the files it created itself, nothing else in the Drive.
  • Files go straight from the owner's computer to the owner's Google Drive. No server in between.
  • No data is collected, stored, shared or sold by this app or anyone else. No analytics, no cookies, no tracking.
  • Access can be removed at any time in the Google Account under Security → Third-party apps and services.
